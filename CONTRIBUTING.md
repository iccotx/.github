# Contributing

## Workflow

1. Create a branch from the default branch (`feature/...`, `fix/...`, `chore/...`).
2. Keep changes small and focused; write clear commit messages.
3. Open a pull request using the PR template.
4. At least **1 approving review** is required before merging.
5. Direct pushes and force pushes to the default branch are blocked.

## Standards

- Make sure builds and tests pass before requesting review.
- Do not commit secrets or sensitive data (see SECURITY.md).
- Update documentation when behavior changes.
- Resolve review comments before merging.

## Access

Access is granted through teams: `*-Admins` (admin), `*-Developers` (write), `*-ReadOnly` (read). Ask an org owner if you need a change.
