# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email **it@wcgtx.com** with:

- A description of the issue and its impact
- Steps to reproduce (proof of concept if possible)
- Affected repository, branch or version

We aim to acknowledge reports within 3 business days and will keep you updated until the issue is resolved.

## Handling secrets

- Never commit credentials, API keys, tokens or patient/customer data.
- If a secret is committed by mistake, rotate it immediately and notify it@wcgtx.com, then remove it from history.
